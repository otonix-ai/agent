# Contributing to Otonix Agent

Thank you for considering a contribution to this project! 😊

## What is a contributor?

A contributor is anyone who helps the project grow. Their roles may include:

- Writing or fixing code.
- Adding or improving documentation.
- Reporting bugs or issues.
- Proposing new ideas or features.
- Reviewing other people’s pull requests.

Contributors help maintain quality, add features, and ensure the project continues.

## How to contribute

1. **Fork** the repository to your GitHub account.
2. Create a new branch for your change (`feature/...`, `fix/...`, etc.).
3. Make your changes; add tests if appropriate.
4. Commit and push to your branch.
5. Open a pull request against the main repository and describe your changes.

> Please adhere to Python style guidelines and run `flake8` or another linter before submitting.

## Common tasks

- Fix bugs reported in issues.
- Add new skills under the `skills/` directory.
- Update documentation in `README.md` or create new pages.
- Write examples or tests.

## Getting your name listed

To have your name appear in the acknowledgments list, add yourself to `CONTRIBUTORS.md` or submit a
pull request with your name/GitHub link. Any meaningful contribution may be included.
